# 🛒 Lista de Mercado
Aplicativo simples para montar e calcular lista de compras, feito em Python + KivyMD.

## Funcionalidades
- ✅ Adicionar produto (nome, quantidade, preço)
- ✅ Calcular subtotal e total geral
- ✅ Interface gráfica com KivyMD

## Como rodar
```bash
pip install kivymd
python main.py
